# Flutter rewrite (1.x)

A full Flutter rewrite of this app is in progress for the 1.x major version. This branch of
work starts with a minimal skeleton (`pubspec.yaml`, `lib/`, `test/`); platform folders such as
`android/` will be generated later by CI via `flutter create`, and features will be migrated
step by step.

The existing [README](README.md) remains valid for the current Kotlin release, 0.1.5. Until the
rewrite ships, build and install instructions there still apply.
