05 / GOOD TO KNOW

A few things, before you go.

Is this an official Cursor app?

No. Cursor Android is an independent community project. It is not affiliated with or endorsed by Cursor or Anysphere. Cursor is a trademark of its respective owner.

Do I need a Cursor account?

Yes, for live features. Cloud Agents use a Cursor API key. Usage belongs to the Cursor web session and is a separate connection. This website preview does not ask for credentials or access your account.

What do the two model pools mean?

They reflect Cursor’s own usage pools. Cursor Model uses autoPercentUsed; Other Model uses apiPercentUsed. They are not inferred from a model’s name, dollar spend, or token totals. There is no Grok Bot pool.

Does usage update continuously in the background?

No. Android schedules background refreshes and can delay them. Notifications and a floating capsule are optional, with permissions controlled by you. The app must show when data was last updated.

Does it replace the desktop editor?

No. This project focuses on agents and usage on your phone. Advanced web tools and account management remain in Cursor. The repository tracks native support and planned capabilities explicitly.

Where do downloads come from?

Published Android packages are linked directly from this project’s GitHub releases. If no APK is published yet, you’ll see the release page and build instructions instead of a placeholder download.
